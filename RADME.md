## 📋 Sobre o Projeto
Script em Python desenvolvido para uma campanha de conscientização ambiental de uma companhia de saneamento. O programa classifica o perfil de consumo de água de diferentes tipos de imóveis e emite alertas educativos aos moradores.

## 🛠️ Tecnologias Utilizadas
* **Python** (Linguagem de programação)
* **Git e GitHub** (Controle de versão e hospedagem)
